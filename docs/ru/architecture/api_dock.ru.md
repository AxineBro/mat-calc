
# Mat-Calc — Документация API

## Обзор

Mat-Calc — веб-приложение для вычислений над матрицами и в области теории информации.  
Бэкенд реализован на Spring Boot, фронтенд — на React + Vite.

API разделён на два основных блока:

- `/api/matrix` — операции над матрицами и решения СЛАУ;
- `/api/info` — вычисления маргинальных и условных распределений, энтропии.

## Базовый URL

```text
http://localhost:8080
```

Во время разработки фронтенд проксирует запросы через Vite, поэтому в коде используются относительные пути вида `/api/matrix/...` и `/api/info/...`.

## Аутентификация

В текущей версии API не требует аутентификации.

CORS настроен на источник:

```text
http://localhost:5173
```

## Общие заголовки

| Заголовок        | Тип    | Обязателен | Описание                                                                 |
| :--------------- | :----- | :--------- | :----------------------------------------------------------------------- |
| `Content-Type`   | string | Да         | Для POST-запросов: `application/json`.                                   |
| `Accept-Language`| string | Нет        | Влияет на язык сообщений в эндпоинтах `/api/info/*`. Например: `ru`, `en`. |

## Обработка ошибок

Все доменные ошибки обрабатываются `GlobalExceptionHandler` и возвращаются в формате:

```json
{
  "message": "Описание ошибки"
}
```

Основные HTTP-статусы:

| Код статуса | Описание                                                             |
| :---------- | :------------------------------------------------------------------- |
| `200 OK`    | Запрос выполнен успешно.                                             |
| `400 Bad Request` | Некорректная матрица, вырожденная матрица, неверное распределение и т.п. |

Исключения, которые приводят к `400 Bad Request`:

- `InvalidMatrixException`;
- `SingularMatrixException`;
- `InvalidProbabilityException`.

## Эндпоинты — Матрицы

Базовый путь: `/api/matrix`.

### 1. Определитель матрицы

**Эндпоинт:** `POST /api/matrix/determinant`

**Тело запроса (`MatrixRequest`):**

```json
{
  "matrix": [[1, 2], [3, 4]]
}
```

| Поле     | Тип          | Описание                         |
| :------- | :----------- | :------------------------------- |
| `matrix` | `number[][]` | Квадратная матрица.              |

> В текущем DTO `MatrixRequest` поле `matrix` объявлено как `Integer[][]`.

**Ответ (`MatrixResponse`):**

```json
{
  "determinant": -2.0
}
```

| Поле          | Тип      | Описание            |
| :------------ | :------- | :------------------ |
| `determinant` | `number` | Значение определителя. |

**Возможные ошибки:**

- `400 Bad Request` — матрица не квадратная или некорректна.

---

### 2. Обратная матрица

**Эндпоинт:** `POST /api/matrix/inverse`

**Тело запроса (`MatrixRequest`):**

```json
{
  "matrix": [[4, 7], [2, 6]]
}
```

**Ответ (`MatrixResultResponse`):**

```json
{
  "matrix": [[0.6, -0.7], [-0.2, 0.4]]
}
```

| Поле     | Тип          | Описание            |
| :------- | :----------- | :------------------ |
| `matrix` | `number[][]` | Обратная матрица.   |

**Возможные ошибки:**

- `400 Bad Request` — матрица не квадратная;
- `400 Bad Request` — матрица вырождена и не может быть обращена.

---

### 3. Собственные значения и собственные векторы

**Эндпоинт:** `POST /api/matrix/eigen`

**Тело запроса (`MatrixRequest`):**

```json
{
  "matrix": [[2, 0], [0, 3]]
}
```

**Ответ (`EigenResponse`):**

```json
{
  "eigenvalues": [3.0, 2.0],
  "eigenvectors": [[0.0, 1.0], [1.0, 0.0]]
}
```

| Поле           | Тип            | Описание                                      |
| :------------- | :------------- | :-------------------------------------------- |
| `eigenvalues`  | `number[]`     | Собственные значения.                         |
| `eigenvectors` | `number[][]`   | Собственные векторы, соответствующие значениям. |

**Возможные ошибки:**

- `400 Bad Request` — матрица не квадратная;
- `400 Bad Request` — матрица имеет комплексные собственные значения (не поддерживается).

---

### 4. Решение СЛАУ методом Крамера

**Эндпоинт:** `POST /api/matrix/solve/cramer`

**Тело запроса (`LinearSystemRequest`):**

```json
{
  "matrix": [[2, 1], [1, 3]],
  "constants": [5, 10]
}
```

| Поле        | Тип          | Описание                             |
| :---------- | :----------- | :----------------------------------- |
| `matrix`    | `number[][]` | Матрица коэффициентов системы.       |
| `constants` | `number[]`   | Вектор свободных членов.             |

**Ответ (`LinearSystemResponse`):**

```json
{
  "solution": [1.0, 3.0]
}
```

| Поле       | Тип        | Описание              |
| :--------- | :--------- | :-------------------- |
| `solution` | `number[]` | Вектор решения системы. |

**Возможные ошибки:**

- `400 Bad Request` — матрица не квадратная;
- `400 Bad Request` — размер вектора `constants` не совпадает с порядком матрицы;
- `400 Bad Request` — определитель равен нулю, система не имеет единственного решения.

## Эндпоинты — Теория информации

Базовый путь: `/api/info`.

Все эндпоинты принимают совместное распределение вероятностей и возвращают пошаговое решение.

### 1. Маргинальные распределения и проверка независимости

**Эндпоинт:** `POST /api/info/marginals`

**Тело запроса (`JointDistributionRequest`):**

```json
{
  "probabilities": [[0.1, 0.2], [0.3, 0.4]]
}
```

| Поле            | Тип          | Описание                                                                 |
| :-------------- | :----------- | :----------------------------------------------------------------------- |
| `probabilities` | `number[][]` | Матрица совместного распределения. Сумма всех элементов должна быть равна 1. |

**Ответ (`SolutionResponse`):**

```json
{
  "answer": "Случайные величины зависимы",
  "sections": [
    {
      "title": "Маргинальные распределения",
      "summary": null,
      "steps": [
        {
          "title": "Формула для p(x_i)",
          "formula": "p(x_i) = \\sum_{j} p(x_i, y_j)",
          "substitution": null,
          "result": null,
          "note": null
        }
      ]
    }
  ]
}
```

**Возможные ошибки:**

- `400 Bad Request` — `probabilities` равно `null`;
- `400 Bad Request` — одна из строк равна `null`;
- `400 Bad Request` — одна из ячеек равна `null`;
- `400 Bad Request` — распределение не прямоугольное;
- `400 Bad Request` — вероятность отрицательна;
- `400 Bad Request` — сумма вероятностей не равна 1.

---

### 2. Условные распределения

**Эндпоинт:** `POST /api/info/conditionals`

**Тело запроса (`JointDistributionRequest`):**

```json
{
  "probabilities": [[0.1, 0.2], [0.3, 0.4]]
}
```

**Ответ (`SolutionResponse`):**

Содержит секции:

- `p(x_i | y_j)`;
- `p(y_j | x_i)`.

Формат аналогичен эндпоинту `/api/info/marginals`.

**Возможные ошибки:**

- `400 Bad Request` — некорректное совместное распределение.

---

### 3. Энтропия

**Эндпоинт:** `POST /api/info/entropy`

**Тело запроса (`JointDistributionRequest`):**

```json
{
  "probabilities": [[0.1, 0.2], [0.3, 0.4]]
}
```

**Ответ (`SolutionResponse`):**

Содержит секции:

- `H(X)`;
- `H(Y)`;
- `H(XY)`;
- частные условные энтропии `H_{y_j}(X)`;
- частные условные энтропии `H_{x_i}(Y)`;
- полные условные энтропии `H_Y(X)` и `H_X(Y)`.

**Возможные ошибки:**

- `400 Bad Request` — некорректное совместное распределение.

## DTO

### `MatrixRequest`

```json
{
  "matrix": [[1, 2], [3, 4]]
}
```

| Поле     | Тип          | Описание             |
| :------- | :----------- | :------------------- |
| `matrix` | `Integer[][]` | Матрица целых чисел. |

### `LinearSystemRequest`

```json
{
  "matrix": [[2, 1], [1, 3]],
  "constants": [5, 10]
}
```

| Поле        | Тип          | Описание                       |
| :---------- | :----------- | :----------------------------- |
| `matrix`    | `Double[][]` | Матрица коэффициентов.         |
| `constants` | `Double[]`   | Вектор свободных членов.       |

### `JointDistributionRequest`

```json
{
  "probabilities": [[0.1, 0.2], [0.3, 0.4]]
}
```

| Поле            | Тип          | Описание                         |
| :-------------- | :----------- | :------------------------------- |
| `probabilities` | `Double[][]` | Совместное распределение.        |

### `MatrixResponse`

```json
{
  "determinant": -2.0
}
```

### `MatrixResultResponse`

```json
{
  "matrix": [[0.6, -0.7], [-0.2, 0.4]]
}
```

### `LinearSystemResponse`

```json
{
  "solution": [1.0, 3.0]
}
```

### `EigenResponse`

```json
{
  "eigenvalues": [3.0, 2.0],
  "eigenvectors": [[0.0, 1.0], [1.0, 0.0]]
}
```

### `SolutionResponse`

```json
{
  "answer": "Краткий ответ",
  "sections": []
}
```

| Поле       | Тип                 | Описание                          |
| :--------- | :------------------ | :-------------------------------- |
| `answer`   | `string`            | Краткий итоговый ответ.           |
| `sections` | `SectionResponse[]` | Секции с пошаговым решением.      |

### `SectionResponse`

| Поле      | Тип              | Описание                          |
| :-------- | :--------------- | :-------------------------------- |
| `title`   | `string`         | Заголовок секции.                 |
| `summary` | `string \| null` | Краткий вывод по секции.          |
| `steps`   | `StepResponse[]` | Шаги решения.                     |

### `StepResponse`

| Поле           | Тип              | Описание                                                                 |
| :------------- | :--------------- | :----------------------------------------------------------------------- |
| `title`        | `string \| null` | Заголовок шага.                                                          |
| `formula`      | `string \| null` | Формула в формате LaTeX.                                                 |
| `substitution` | `string \| null` | Подстановка значений в формате LaTeX.                                    |
| `result`       | `string \| null` | Результат шага.                                                          |
| `note`         | `string \| null` | Примечание.                                                              |

### `ApiError`

```json
{
  "message": "Описание ошибки"
}
```

## Ограничения

- Матрица не должна быть пустой.
- Матрица должна быть прямоугольной.
- Для операций `determinant`, `inverse`, `eigen`, `cramer`, `solveByInverse`, `gauss` матрица должна быть квадратной.
- Для `cramer`, `solveByInverse`, `gauss` длина вектора `constants` должна совпадать с порядком матрицы.
- Совместное распределение должно быть неотрицательным и в сумме давать `1` с точностью `1e-6`.
- Максимальный размер матрицы на фронтенде — `10 × 10` (ограничение UI, не API).
